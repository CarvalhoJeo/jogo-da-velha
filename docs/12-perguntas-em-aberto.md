# Perguntas em aberto

O guia não informa datas, pesos de avaliação nem tamanho do grupo. Confirmar com o professor:

- [ ] O professor aprova o Jogo da Velha e a stack em Java?
- [ ] Qual é a data de entrega e há entregas parciais por semana?
- [ ] Quais são os pesos de cada critério de avaliação?
- [ ] O projeto é individual ou em grupo? Quantos membros?
- [ ] Qual é a duração da apresentação?
- [ ] Como é a entrega: link do repositório, PDF ou os dois?
- [ ] O cliente precisa ter interface gráfica ou um cliente de console é aceito?
- [ ] Certificado autoassinado é aceito, ou é preciso um domínio com Let's Encrypt se houver deploy na nuvem?
